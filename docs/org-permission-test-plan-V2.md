## 0. 四个视角（Persona）与判定维度

权限 = **平台角色（超管）× 组织角色（OWNER/ADMIN/MEMBER）× 组织类型（INDIVIDUAL/TEAM）** 三者正交。

| 代号 | 视角 | 身份 | 当前组织上下文 | 测试账号 |
|---|---|---|---|---|
| **P-超管** | 平台管理员 | `ragRole=ADMIN` | 默认按本人；跨组织需**破玻璃**（`X-Admin-Override`） | `ADMIN` (admin) |
| **P-企管** | 企业组织管理员 | 某 TEAM 组织的 `OWNER`/`ADMIN` | `X-Org-Id = 该 TEAM 组织` | `U_RAG`（建组织即 OWNER） |
| **P-员工** | 企业普通员工 | 某 TEAM 组织的 `MEMBER` | `X-Org-Id = 该 TEAM 组织` | `U_OTHER`（被加为 MEMBER） |
| **P-个人** | 个人组织 | 自己 INDIVIDUAL 组织的 OWNER | `X-Org-Id = 本人 INDIVIDUAL 组织` | `U_RAG` / `U_OTHER` 本人 |

**关键请求头**
- `X-Org-Id: <orgId>` —— 当前所在组织（数值）。前端切组织时注入。
- `X-Admin-Override: true`（+ reason）—— 仅超管破玻璃看全平台时。

**图例**：✓ 允许/可见 · ✗ 拒绝/不可见 · ⚠️ 有条件 · — 不适用

## 模块 M1：组织生命周期（创建 / 编辑 / 升级 / 转移 / 删除 / 退出）

| # | 操作 | P-超管 | P-企管(OWNER) | P-员工(MEMBER) | P-个人 | 隐藏 bug 关注点 |
|---|---|---|---|---|---|---|
| M1-01 | 注册新用户后首次 `GET /orgs` | ✓ | ✓ | ✓ | ✓ 自动懒建 INDIVIDUAL 组织 | 并发首登只建**一个**个人组织（唯一索引 `uq_org_individual_owner`） |
| M1-02 | 创建组织 `POST /orgs` | ✓→TEAM | ✓→TEAM | ✓→TEAM | ✓→TEAM | 新建一律 `type=TEAM`；slug 非法/占用返回 400/409 |
| M1-03 | 个人组织出现在 `GET /orgs` 且 `personal=true,type=INDIVIDUAL` | ✓ | ✓ | ✓ | ✓ | 列表**不得**重复出现两个个人组织 |
| M1-04 | 升级个人组织 `POST /orgs/{个人org}/upgrade` | ⚠️ 仅本人 | — | — | ✓ INDIVIDUAL→TEAM | 升级后 `org_id 不变`、其下知识库**零迁移**（库 org_id 不变） |
| M1-05 | 对 TEAM 组织调用 upgrade | ✗ 409 NOT_INDIVIDUAL_ORG | ✗ 409 | ✗ 409 | — | 已是 TEAM 不可再升级 |
| M1-06 | 编辑组织 `PATCH /orgs/{id}` | ⚠️ 破玻璃 | ✓ 本组织 | ✗ 403 | ✓ 自己组织 | 员工改组织名应 403 |
| M1-07 | 转移所有权 `POST /orgs/{id}/transfer-owner` | ⚠️ | ✓ 仅 OWNER | ✗ 403 | ✓ 单人转移须目标在组织内 | ADMIN（非 OWNER）转移应 403 |
| M1-08 | 删除组织 `DELETE /orgs/{id}` | ⚠️ | ✓ 仅 OWNER | ✗ 403 | ⚠️ 个人组织删除应被拒/约束 | 名下有库时应先清空（否则约束报错），不可级联误删库 |
| M1-09 | 退出组织 `POST /orgs/{id}/leave` | ✓ | ⚠️ OWNER 不可直接退出（须先转移） | ✓ MEMBER 可退出 | ✗ 个人组织无「退出」 | OWNER 退出导致组织无主 = bug |
| M1-10 | 越权访问他人组织详情 `GET /orgs/{别人的org}` | ⚠️ 破玻璃 | ✗ 非成员 403/404 | ✗ 403/404 | ✗ 403/404 | 非成员能读他组织信息 = 越权泄漏 |

## 运行

```bash
# 前置：后端（含 V48~V50 迁移）+ 前端 dev(5173) 运行；种子账号已建（ensureQaAccounts）
cd frontend
RAG_WEB=http://localhost:5173 \
  npx playwright test tests/e2e/org-permissions.spec.ts --reporter=line
```

- 默认 `RAG_WEB=http://localhost:5173`，`RAG_API=$RAG_WEB/api`；可用环境变量覆盖账号（见 `unified-auth/fixtures/accounts.ts`）。
- spec 内每条用例标注对应本文档编号（如 `M3-04`），便于双向追溯。
- 纯过滤/越权类用例为 **API 驱动**（直接打后端、构造 `X-Org-Id`/`X-Admin-Override`）；路由守卫类（M8）走 UI。
